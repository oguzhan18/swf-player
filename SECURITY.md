# Security policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Contact the maintainer via [GitHub](https://github.com/oguzhan18) private communication or the contact options listed on [oguzhancart.dev](https://oguzhancart.dev/).

Include a clear description, reproduction steps, and impact if known.
